# Plan — 069 Morpho earn registry (backend)

**Branch:** `feat/069-morpho-earn-registry` (stacked on 068) · **Worktree:**
`~/project/sparkpoint-pivot-069`.

## Design

### 1. Package + config (`earn/earn.json`, `earn/config.py`)

`earn.json` ships enabled chains (Base 8453, Ethereum 1; others listed but disabled), filters
(`listed_only`, `min_tvl_usd=1,000,000`, assets USDC/WETH/USDT/cbBTC), allow/deny lists, known vault
names, curated defaults (Gauntlet USDC Prime on Base), the four 1Click receipts, and rails flags
(`direct=true`, `oneclick_earn=true`, `intents_connect=false`). `EARN_CONFIG_PATH` overrides the file;
`EARN_ENABLED` overrides `feature_enabled`. `EARN_DATA_DIR` / `EARN_SNAPSHOT_PATH` control the writable
snapshot location.

### 2. Registry (`earn/registry.py`)

`fetch_vaults` asks Morpho `vaults` (V1) and `vaultV2s` (V2) in **separate** requests, with
`where:{chainId_in:[…]}` and pagination. V1 reads `state{totalAssetsUsd netApy}`; V2 reads top-level
`totalAssetsUsd netApy avgNetApy`. V2 pages are 500 items because `first:1000` with `avgNetApy`
exceeds Morpho's complexity cap (403 "Query is too complex"). Normalize to `VaultEntry` (Decimal TVL /
APY fraction), apply filters/allow/deny, sort by TVL.

`EarnRegistry` loads the persisted snapshot first, then the shipped fallback; `refresh()` fetches and
persists atomically, failing open to the previous snapshot. `refresh_loop` is the background cadence
(floored interval, cancellation-safe, no DB). The shipped `snapshot.json` is generated by
`scripts/earn_registry_snapshot.py`.

### 3. Rails (`earn/rails.py`)

- `direct`: same-chain ERC-4626 when the chain is enabled; native Morpho share.
- `oneclick_earn`: receipt matched by `underlying_vault`; liveness `live|no_liquidity|unknown` from
  a TTL cache updated by background dry quotes. Unknown stays available (a preview asks 1Click);
  probed no-liquidity is unavailable. Carries `receiptNote` and keyless `feeNote`.
- `intents_connect`: gated by `rails.intents_connect` + `AURORA_INTENTS_API_KEY` + configured
  per-chain asset. Emits `approve(address,uint256)` then `deposit(uint256,address)` with
  `{MIN_AMOUNT_OUT}` / `{USER_ADDRESS}` placeholders. Never submits.

### 4. Service (`earn/service.py`)

`list_vaults` filters/sorts and attaches rails. `resolve_vault` matches a name/address or falls back
to the chain's curated default. `preview_for` chooses: same-chain origin → direct hint (no network);
cross-chain origin with a receipt → dry 1Click quote; Intents Connect → step plan; otherwise an
honest unavailable card. `build_service_from_env` returns `None` when disabled.

### 5. HTTP (`api/earn.py`)

`GET /earn/vaults` (chain/asset/rail/min_tvl/limit≤200/sort) and `GET /earn/vaults/{chain}/{address}`
read the snapshot. `POST /earn/preview` validates chain/origin/amount, rejects `dry=false`, and
returns the `earn_quote` wire. `get_account` + a per-owner sliding-window limiter (120/h) match 068.

### 6. Chat (`earn/parse.py`, `coordinator/chat_blocks.py`, `coordinator/dag.py`)

Parser fires only on an explicit Morpho mention or a configured vault name:
- list: list verb + "vault(s)" + Morpho/known name → `earn_vaults` (top 5, sort TVL or APY).
- deposit: action verb + amount/symbol + a Morpho/known-name target → `earn_quote` preview.
`origin_chain` from "from Ethereum" lets a cross-chain origin use the receipt rail. The hook runs
after 068 and before the upsell/bridge/planner routes. `earn_vaults` / `earn_quote` are persisted
with the turn.

### 7. Scripts + background

- `scripts/earn_registry_snapshot.py`: ≤6 Morpho requests (V1 enabled + V2 enabled at 500/page),
  writes `earn/snapshot.json`, prints per-chain/asset/rail counts and the all-vaults table.
- `scripts/earn_dry_smoke.py`: real dry Base-USDC-100 quotes per receipt.
- `api/main.py` starts `run_earn_loop` (refresh + receipt probes) and cancels it on shutdown.

### 8. Phase B (pending)

Shared zod `earn_vaults` / `earn_quote` schemas, the web list/preview card, and the live
deposit/withdraw flow (reusing the 068 confirm pattern). No web files in this backend half.
