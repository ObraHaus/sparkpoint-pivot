Proposed implementation (after your approval)

  • Bundle locally under apps/web/public/tokens/<symbol>.<svg|png> — no remote hotlinking, no CDN outage/geo-block risk, no token address sent to a third party.
  • Extend lib/logos.ts with a local-first map keyed by chain + address (4663 stocks + USDG; 84532/8453 ETH/USDC), then keep the existing Trust Wallet CDN fallback, then the letter avatar. The verified-address rule stays: a symbol logo is only used for a verified token.
  • Add TokenLogo to the vault cards (feature + live cards) and the portfolio rows — currently they are text-only.
  • Decorative only, never a trust signal — the verified/unverified badge remains authoritative (existing rule, unchanged).
  • Licensing note: USDG/ETH/USDC/WETH are the issuers' official marks; the stock logos are company trademarks used nominatively for identification (via Wikimedia Commons / Simple Icons). If you want zero trademark exposure, we keep the letter avatars for the stocks.
Gaps: SPY, QQQ, GLD have no reliable public logo — recommend the avatar or operator-supplied art. USDG's official file is only 32×32 (fine at 20–34px UI sizes). CRCL is a monochrome mark.
