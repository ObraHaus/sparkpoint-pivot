Vault page redesign — three card-first options

Direction: Sparky recommends one vault at the top, then all live vaults as cards (no table) with badges, a 30-day APY sparkline and deposit CTAs. Only wrapped, depositable vaults are public — candidates, approved-but-unwrapped, whitelisted/cooling, cancelled and failed rows live in the admin panel only. All numbers below are mock.

VISIBILITY RULE
Public /vault shows
  • Wrapped vaults only — a wrapper is deployed, the deposit rail is live.
  • Published picks/alternates that are wrapped (the hero must be depositable).
  • Badges + figures from the stored scan (net APY, TVL, liquidity, age, score).
  • Honest empty state when nothing is live yet.
Admin panel only Admin → Vaults
  • Candidate queue, approve/deny/pin/hide, provenance (AI / Admin).
  • Approved but unwrapped, AI whitelisted / cooling-off / ready, release, cancel.
  • Deploy-now, wrapper params, cooldown, tx + error records.
  • Uncurated / hidden / denied / failed — never merged into the public list.
Net effect: the public page can only ever show something a user can actually deposit into today; everything in flight is operator-only. No “coming soon” rows, no dead CTAs.

CARD ANATOMY

Every card, same skeleton

  • Header: name + curator/asset line · badges (AI/Admin, Wrapped, New, perf-fee).
  • Figure: big net APY (green, tabular) + 30d sparkline.
  • Metrics: TVL · withdrawable · perf-fee (three columns).
  • Why (optional): one stored reason line for picks/alternates.
  • CTA: primary Deposit + secondary Details / Ask Sparky.
  • Footnote: “as of <scan>” on the board; no projections.
Honesty rules stay: figures are stored scans (never 0 for unknown), the perf-fee line is performance-only above HWM, and the deposit rail disclosure is unchanged.
STATES & MOBILE

Edge cases

  • Loading: hero skeleton + 3 card skeletons (no spinner-only).
  • Empty (nothing live): “Sparky is screening vaults — nothing is depositable yet.” + Ask Sparky CTA.
  • Error: the board read failed — wallet/funds unaffected; retry on next poll.
  • Mobile: hero stacks (chart below), grid → 1 column, CTAs full-width; filters become a horizontal chip scroll.
  • Accessibility: badges are text+icon (not color-only); charts have an accessible summary line.
